# Open Contacts

Lane `expressive`. Kit SHA `1ad3166d0839ea042379f5a861ed7523cb46d47e`. Branch `lab/wc-foundry-lane-expressive-20261109`. This note does not give an aim or a placement. Measured orders are in [SOLUTIONS.md](SOLUTIONS.md).

## Concept

An open clearing with no target. Five metal plates stay put. One timber bank can be moved. The player fires, hears and sees which pieces the ball touches, and tries another shot. The reason to fire again is that the contact order can change. The player can do that by aiming, and also by moving the bank. Nothing has to be built before the first shot. The opening arrangement is the world a player enters. It is not empty, and it is not a required phrase.

This is a workshop, not a shot study. There is no challenge id and no landing circle.

## How it differs from Musical Workshop

Musical Workshop is one ramp, one bank, and one plate, all movable, with the ramp on the opening line. Open Contacts has no ramp. The plates are fixed. Only the timber bank is movable. The degrees on the plates are the existing scale, metal only. The bank is timber, degree 0, which is the piece Musical Workshop sound H colors, and only that role. No new sound code was added.
