# Courtyard diverter — loading-dock revision

The original PR #16 additive Dispatch Bay and standalone sorting floor are retired from this experimental route. `/lab/courtyard-diverter` now reuses the existing Mill Bell and the mill loading-platform footprint. `/lab/lines` adds the provisional line receipt and shared setup links using the same experimental dock.

The normal courtyard retains its original loading platform, all three cards, and persistent Skip Pad. Both lab routes replace only the dock body with the switchable version; they do not add another landing cylinder. The two-state Retry/Reset/Recall contract remains in force. New experimental storage keys keep old-layout saved lines separate.

See [the line-instrument contract](line-instrument.md) for physical authority, **NON-CANONICAL PLACEHOLDERS**, ShareLineV1, verification, and the open design questions. Source fixtures are verification tools, not instructions placed in the game.
